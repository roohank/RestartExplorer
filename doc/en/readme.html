RestartExplorer

An NVDA add-on that restarts the Windows Explorer process with a single command.

Features

  • Restarts explorer.exe instantly with a single command.
  • Runs silently in the background without freezing NVDA.
  • Provides audio feedback via NVDA's speech.
  • No default keyboard shortcut, so it never conflicts with other NVDA commands or add-ons.

How to Use

This add-on does not assign a default keyboard shortcut. This is intentional, to avoid conflicts with NVDA's built-in commands (such as Remote Access) and with other add-ons.

To assign your own shortcut:

  1. Open the NVDA menu (NVDA + N).
  2. Go to Preferences → Input Gestures.
  3. In the tree view, find RestartExplorer.
  4. Select Restart the Windows Explorer process.
  5. Click Add, press your desired key combination, and confirm.
  6. Click OK.

After that, pressing your chosen shortcut will restart Windows Explorer. NVDA will announce:

  • "Restarting Explorer..." while the operation is in progress.
  • "Explorer restarted successfully." when done.

If something goes wrong, NVDA will announce the error message.

Requirements

  • NVDA version 2019.3 or later.
  • Windows 10 or Windows 11.
